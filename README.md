# Row & Stitch Counter

A simple browser-based row and stitch counter for crochet and knitting. Counts are saved locally in your browser.

[Use the counter](https://counter.maymayscrochets.com/)

## Development

This is a static site with no build step. After changing `styles.css` or `counter.js`, update its version query in each HTML file that loads it to prevent stale cached files after deployment.
